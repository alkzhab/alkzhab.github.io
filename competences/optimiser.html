Description de la compétence

Ce bloc vise à analyser un problème informatique et à choisir les structures de données ainsi que les algorithmes les plus adaptés pour le résoudre efficacement. L'objectif est de réduire le temps d'exécution et la consommation de ressources matérielles d'une application.

Pourquoi je pense l'avoir acquis ?

Dans mes projets, notamment avec le langage C, j'ai été confronté à la gestion de la mémoire et à l'optimisation d'algorithmes de pavage complexes. Pour le jeu Tetris, j'ai dû concevoir une boucle de jeu fluide en optimisant la détection des collisions, ce qui m'a appris l'importance de la complexité algorithmique.

Ce qu'il me reste à acquérir

J'aimerais approfondir l'utilisation d'outils de profilage de code pour détecter plus précisément les fuites de mémoire, ainsi que me former à l'optimisation des requêtes SQL très volumineuses.

Savoir-faire acquis

  • Structures de données : Choix pertinent (listes, arbres, graphes) selon le besoin.
  • Analyse de complexité : Évaluer l'efficacité spatiale et temporelle d'un algorithme.
  • Optimisation du code : Refactoring pour améliorer les performances.
